#Project Overview :-
This project presents an interactive Customer Retention & Churn Analysis Dashboard developed in Power BI using the Telco Customer Churn dataset. The dashboard is designed to help businesses monitor customer retention, analyze churn patterns, and identify the key factors that influence customer attrition.

The dashboard provides a comprehensive view of customer behavior through interactive visualizations and key performance indicators (KPIs), enabling stakeholders to explore churn trends across contract types, internet services, payment methods, tenure groups, and customer demographics. These insights support data-driven decision-making and help organizations develop effective customer retention strategies.

This project was completed as Task 2 during the Future Interns Data Science Internship, demonstrating practical skills in Power BI, Power Query, DAX, data modeling, and business intelligence.
